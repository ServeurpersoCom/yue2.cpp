# Lyric Style File Schema

Use this format when adding future styles.

```md
# Style Name

## Purpose
One-sentence definition of the intended lyrical behavior.

## Style Lock
Instruction that the generator must enforce the style structurally.

## Core Profile
- Energy
- Delivery Speed
- Target Syllables
- Rhyme Density
- Internal Rhyme Density
- Multisyllabic Rhyme Level
- Punchline Frequency
- Wordplay Level
- Metaphor Density
- Vocabulary
- Storytelling Level
- Aggression
- Emotional Intensity
- Repetition
- Flow Variation
- Preferred Rhyme Schemes
- Bar Structure
- Hook Compatibility

## Mandatory Writing Rules
Concrete rules the model must satisfy.

## Avoid
Style-breaking behavior.

## Generation Procedure
Drafting and revision procedure.

## Style Compliance Check
Binary self-checks.

## Failure Conditions
Conditions that force regeneration.

## App Instruction
How the app should enforce the preset.

## Combination Behavior
How this style behaves when mixed with another.
```
